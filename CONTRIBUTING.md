# Contributing

Backlog.fyi is open source so that you can read it, audit how it handles your data, and run it yourself.

It is also a solo project, and it is meant to stay one: **pull requests are not accepted**, and unsolicited ones will be closed without review. This is not a judgment on anyone's work. It keeps the direction, scope and ownership of the project with a single maintainer (which also means no contributor license agreement is needed).

## What is welcome

- **Bug reports and questions**, as [GitHub issues](https://github.com/Itaypk/Taskboard/issues). Please include what you did, what you expected, and what happened.
- **Feature ideas**, as issues too. They are appreciated as feedback, but there is no promise they will be built. The existing issues are the roadmap; check them first.
- **Forks.** The [AGPL-3.0](LICENSE) lets you fork and modify the code. If you run a modified version as a network service, you must offer its users the corresponding source.

## Security issues

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting (the repository's **Security** tab → **Report a vulnerability**).
